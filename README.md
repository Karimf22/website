# Karim M. Faraj — personal website

A responsive academic website with a warm, vintage minimalist design. Content is based on Karim's curriculum vitae.

## Files

- `index.html`: personal introduction, research, publication, education, teaching, honors, and contact.
- `cv.html`: complete academic CV with print styles and a Print / save as PDF button.
- `styles.css`: responsive layout, paper palette, typography, and print styles.
- `site.js`: navigation highlighting and the CV print action.
- `favicon.svg`: site icon.

The public pages use a telephone number as the only personal contact detail.

## Preview and edit

Open `index.html` in a browser, or serve this folder with a static HTTP server. No package installation or build step is needed. Both pages use local assets and system fonts.

## GitHub Pages

In the repository's Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Changes committed to `main` will publish automatically once Pages is enabled.

Expected website address: https://karimf22.github.io/website/
