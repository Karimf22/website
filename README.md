# Website

A minimal starter website, ready to customize.

## Edit the website

Edit `index.html` to change the text, layout, and styles. Open the file in a browser to preview it locally. No installation or build step is required.

## Publish updates

GitHub Pages is configured to publish the `main` branch from the repository root. Commit changes to `main` to update the website.

Website address: https://karimf22.github.io/website/

Repository: https://github.com/Karimf22/website

Keep passwords, API keys, and local environment files out of this public repository.
